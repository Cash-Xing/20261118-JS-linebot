# 20261118 JS-linebot

以 Node.js 與 [linebot](https://www.npmjs.com/package/linebot) 製作的 LINE 機器人。使用者傳送文字或位置，機器人依內容回覆農場、YouBike、附近停車場與附近公車的查詢結果。

## 功能與指令

| 使用者輸入                                                | 回覆內容                                                                                       | 使用的資料                         |
| --------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | ---------------------------------- |
| `查農場 〇〇`                                             | 名稱包含關鍵字的農場，最多 3 筆（Flex 卡片）                                                   | 農業部農場資料                     |
| `wda`                                                     | 查詢選單（課程介紹、查農場、新北 YouBike、附近停車場、附近公車）                               | —                                  |
| 傳送位置（選單「新北ubike」，或沒有先輸入任何查詢指令時） | 距離最近的 YouBike 站點                                                                        | 新北市 YouBike2.0                  |
| `附近停車場` → 傳送位置                                   | 最近 3 座停車場，含剩餘車位、總車位、收費、地址與導航按鈕                                      | 新北市路外停車場資料與即時車位     |
| `附近公車` → 傳送位置                                     | 最近 3 個公車站牌（1 公里內），含距離、即將經過的班次數，以及前 5 班的路線、方向與剩餘到站時間 | 新北市公車站位、路線與預估到站時間 |

補充說明：

- 「附近停車場」與「附近公車」會先請你傳送位置。位置要在輸入指令後 10 分鐘內傳送，逾時會改回 YouBike 查詢。
- 停車場沒有即時資料時，卡片會顯示「無即時資料」。
- 公車卡片的「共 N 班即將經過」是該站牌目前有效的到站班次數，不是一整天的班次數。

## 安裝與執行

### 環境需求

- Node.js 18 以上（開發時使用 Node.js v24）
- 已在 LINE Developers 建立 Messaging API 頻道

### 步驟

1. 安裝套件

   ```bash
   npm install
   ```

2. 建立 `.env`，可參考 `.env.sample`

   ```env
   CHANNEL_ID=你的 Channel ID
   CHANNEL_SECRET=你的 Channel secret
   CHANNEL_ACCESS_TOKEN=你的 Channel access token
   DEBUG=            # 選填，設定後農場卡片傳送失敗時，會把除錯資料寫入 dump/flex.json
   PORT=3000         # 選填，預設 3000
   ```

   `.env` 已列在 `.gitignore`，不要把金鑰提交到 Git。

3. 啟動

   ```bash
   npm start          # 一般啟動
   npm run dev        # 使用 nodemon，檔案變更後自動重啟
   ```

   看到「機器人啟動」代表服務已經在 `PORT` 上監聽。

### 設定 LINE Webhook

1. 到 LINE Developers Console 的 Messaging API 設定頁。
2. 將 **Webhook URL** 設為 `https://你的網址/`（機器人接收 webhook 的路徑是 `/`）。
3. 開啟「使用 Webhook」。

本機測試時，LINE 無法直接連到 `localhost`，需要用 ngrok、cloudflared 等工具提供公開的 HTTPS 網址。

## 開發

- 格式：Prettier（寬度 100、不加分號、使用單引號）。
- 檢查：
  ```bash
  npx prettier --check index.js commands templates utils
  npx eslint .
  ```
- 換行請使用 LF，與倉庫中的檔案一致。若 Git 設定了 `core.autocrlf=true`，`git status` 可能把檔案顯示為已修改，但 `git diff` 不會有內容差異，可以忽略。

## 注意事項

- **等待位置的狀態存放在記憶體中**：機器人重新啟動後，尚未傳位置的查詢會被清除。
- **停車場**：部分停車場沒有即時車位資料，卡片會顯示「無即時資料」。這是資料來源本身的限制。停車場座標是 TWD97 平面座標，程式會用 `proj4` 轉成經緯度。
- **公車到站時間**：資料中的負數是狀態代碼（例如未發車、不停靠、末班已過、未營運），程式不會把它當成秒數，也不會計入班次數。這些代碼的定義依臺北市的規格文件推測，新北是否完全相同尚未確認。
- **快取**：公車站位與路線資料啟動時預先載入，快取一天；到站時間快取 30 秒。第一次查詢公車時會比較慢。
- **資料更新**：公開資料的欄位與內容可能隨時變動，發生錯誤時請先檢查資料來源是否改版。
